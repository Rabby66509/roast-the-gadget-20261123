One original line roasting a gadget used every day — a phone whose autocorrect keeps turning "on my way" into "on my whale" — written to `/output/entry.txt` for make.fun's "One-Line Roast: The Gadget You Use Every Day" bounty. A single stdlib-only Python program, no dependencies, no network.

## Run it

```sh
python3 main.py
```

The program writes the 120-character roast to `/output/entry.txt` (override with `ENTRY_OUTPUT=/tmp/entry.txt python3 main.py` for a local run). It refuses to write a line that is empty or over the competition's 200-character cap.
